# Focus Max

Eclipse の Ctrl+M のように、VS Code で作業中の領域を **Ctrl+Alt+M** で最大化する拡張機能です。もう一度押すと表示を復元し、最大化した領域にフォーカスを戻します。

## インストール

VS Code 1.110 以降の 1.x 系に対応しています。コマンドパレットで `Extensions: Install from VSIX...` を実行し、このフォルダーの [focus-max.vsix](./focus-max.vsix) を選択してください。

## 使い方

広げたい領域をクリックし、Ctrl、Alt、M の3つのキーを同時に押します。

| フォーカスしている領域 | Ctrl+Alt+M を押したときの動作 |
| --- | --- |
| エディタ | 表示中のサイドバーとパネルを隠し、エディタ領域全体を広げます。左右や上下に分割している場合も、すべてのグループをその配置のまま表示します。 |
| プライマリサイドバー（エクスプローラーなど） | セカンダリサイドバーとパネルを隠し、プライマリサイドバーを広げます。復元時は最小幅まで縮むため、操作前の幅に戻すには境界をドラッグしてください。 |
| セカンダリサイドバー（Codex など） | VS Code 標準のサイドバー最大化を切り替えます。Codex がこの領域にある場合は、チャット画面から操作できます。 |
| パネル（統合ターミナル、出力など） | 表示中のサイドバーを隠し、パネルを最大化します。必要に応じてパネルの配置を一時的に中央揃えにし、復元時に元の配置へ戻します。 |
